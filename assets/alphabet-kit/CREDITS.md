# Alphabet Education Kit

Ilustrações originais do arquivo fornecido pelo usuário:
`craftpix-net-370419-free-alphabet-vector-asset-kit-for-education-games.zip`.

Autor e origem: [CraftPix](https://craftpix.net/).
Licença indicada no pacote: <https://craftpix.net/file-licenses/>.

Foram utilizados os SVGs de 52 objetos, 26 letras em três estilos,
quatro cenários, sete poses do gato e 12 elementos de interface (153 imagens).
Nomes de arquivo foram simplificados para uso na web. As legendas em inglês
dos objetos foram removidas e a área de exibição ajustada; os jogos apresentam
rótulos acessíveis em português. Duplicatas de PNG/AI,
arquivos de sistema do macOS e prévias de composição não são necessários para
executar os jogos. Os SVGs mantêm a nitidez em qualquer tamanho de tela.

Os nomes dos objetos e as atividades foram adaptados para português brasileiro;
a letra inicial é calculada pelo nome em português, não pelo arquivo em inglês.
